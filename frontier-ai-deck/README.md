# Frontier AI scale & trajectory — draft deck (v1)

Three draft slides for iterative review: present state, scale trajectory (combined
OpenAI + Anthropic chart), and the 8–10T next-generation scenario.

- `frontier-ai-scale-trajectory.pptx` — the deck (speaker notes included)
- `frontier-ai-scale-trajectory.pdf` — rendered copy for quick review
- `SOURCES.md` — every plotted number with status (disclosed / estimate / unconfirmed / scenario) and links
- `chart.js` — generates the slide-2 chart (`node chart.js` → `chart.png`)
- `build_deck.js` — builds the deck (`node build_deck.js`)

Rebuild: `npm install && node chart.js && node build_deck.js`
